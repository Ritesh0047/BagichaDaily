# Bagicha Daily - Apple Ecommerce

A React ecommerce website for selling fresh apples, built with Vite and Tailwind CSS.

## Setup

```bash
npm install
```

## Development

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Tech Stack

- **React 18** - UI library
- **Vite** - Build tool
- **Tailwind CSS** - Styling
